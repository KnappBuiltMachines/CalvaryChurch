# Event images

Drop registration artwork here, then reference it in `app/site.js` as
`image: "/events/filename.jpg"`.

Expected files (from Church Center):
  summer-bible-club-2026.jpg
  vbs-2026-wonder-junction.jpg
  awana-2026-2027.jpg

How to get them:
  1. Go to https://cchammonton.churchcenter.com/registrations/events
  2. Right-click each event image > "Save image as..."
  3. Name it to match the list above and upload it into this folder.

Landscape artwork works best (roughly 16:9). Keep files under ~300 KB
so pages stay fast — most Church Center logos already are.

If an image is missing, the card falls back to an icon. Nothing breaks.
