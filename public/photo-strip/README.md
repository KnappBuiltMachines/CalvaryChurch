# Home page photo strip

Every photo in this folder scrolls across the home page, just below the service times.

**To add photos:** click **Add file → Upload files** above, drag in a batch of photos, then click **Commit changes**. The site updates in about a minute.

**To remove a photo:** click it, then use the **⋯** menu → **Delete file** → **Commit changes**.

Tips
- Use **JPG**, PNG or WebP. iPhone **HEIC** photos won't show. On iPhone, sharing or AirDropping a photo with *Options → Most Compatible* gives a JPG, and exporting from Photos on a Mac also gives JPGs.
- Big phone photos are fine: the site shrinks them automatically for visitors.
- GitHub takes up to 100 files at a time, 25 MB each.
- This repository is public, so anyone can download the original files here.
