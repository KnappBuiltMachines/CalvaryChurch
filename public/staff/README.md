# Staff photos

Upload headshots here, then reference them in `app/site.js` under `staff`
as `photo: "/staff/filename.jpg"`.

Tips:
  - Square photos work best. They're shown in a circle, so keep the face centered.
  - About 600 x 600 pixels and under ~200 KB keeps the page fast.
  - Use lowercase names with dashes, e.g.  jane-smith.jpg

If a photo is missing, the page shows the person's initials instead. Nothing breaks.
